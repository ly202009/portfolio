KNN Project
A capstone project directed towards the goal of making a working content recommendation algorithm, similar to the kinds on social media platforms. With Python, datasets from kaggle, 270,000+ users and 24,000+ animes, it can predict with an optimized K=150, an average error rate of 2.2 on a scale of 10, and an RMSE of 3.17.
Github Repository Capstone Presentation
Python Enigma M3 Encoder
Inspired by the YouTuber "Code Bullet" as well as the movie "The Imitation Game", I set out to code an Enigma machine of my own. This program allows adjustment for initial positions, plugboard settings, ring settings, rotor order, and comes with the same rotors used back then.

Made with pure Python and a bit of frustration.
